# 调查员助手 · 在线版

面向《克苏鲁的呼唤》第七版的跑团辅助工具。**零依赖、单文件** —— 点开即用，无需安装，无需联网；所有数据只保存在你自己的浏览器里。

## 打开方式

**在线使用（推荐）**

<https://p1anez.github.io/coc-toolkit/>

**离线使用**

在本仓库点开 `index.html`，用右上角的「Download raw file」按钮保存到本机，双击即可打开。不需要安装任何东西，也不需要联网。

## 能做什么

- **车卡向导**：属性、技能点、背景、装备，全程校验
- **角色卡**：点击技能或属性打开检定抽屉，含难度档与奖励 / 惩罚骰
- **理智**：理智检定、疯狂发作，恐惧症与躁狂症记录
- **战斗轮 / 追逐轮**：按规则结算
- **规则数据**：职业、武器、毒剂、物价等已内建
- **三套配色**：在「存档与数据」页切换

## 数据存在哪里

所有数据保存在浏览器的本地存储（localStorage）里，不上传任何服务器。

- 换电脑、换浏览器，数据不会跟过去
- 清理浏览器数据会连同角色一并清掉
- 重要角色请在「存档与数据」页导出 JSON，单独留一份备份

## 关于本仓库

本仓库是**成品货架**：只存放构建产物，由源码仓库的发布脚本自动同步。请勿在此直接修改文件 —— 改动会在下次同步时被覆盖。
